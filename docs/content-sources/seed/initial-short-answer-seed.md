# 초기 단답형 시드 문항

> [!warning] 내부 원천 자료
> 이 문서는 초기 앱 골격 검증을 위해 직접 작성한 시드 문항의 관리용 참고 자료다. 앱에는 이 문서 자체를 포함하지 않고, 앱 문항은 `sourceType: "rewritten"`으로 관리한다.

초기 시드 문항은 각 주요 카테고리의 필터, 채점, 대소문자 정책이 동작하는지 검증하기 위해 작성했다.
