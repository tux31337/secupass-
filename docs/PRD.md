# PRD: 정보보안기사 실기 단답 트레이너

## 목표
정보보안기사 실기 시험을 준비하는 사용자가 모바일에서 단답형 문제를 빠르게 반복 풀이하고, 대소문자 채점 기준을 명확히 확인하며 오답을 복습할 수 있게 한다.

## 사용자
- 정보보안기사 실기 시험을 준비하는 수험생
- 이동 중 짧은 시간에 핵심 용어, 명령어, 경로, 보안 개념을 암기하고 싶은 사용자
- 단답형 답안에서 대소문자를 구분해야 하는지 헷갈리는 사용자

## 핵심 문제
- 단답형은 답을 알고 있어도 표기, 약어, 대소문자 기준 때문에 헷갈린다.
- 모바일에서 짧게 풀고 바로 채점되는 학습 흐름이 필요하다.
- 틀린 문제와 헷갈린 문제를 다시 모아 보는 기능이 필요하다.
- 기출 원문을 무단 수록하면 저작권과 앱 심사 리스크가 있다.

## v1 핵심 기능
1. 단답형 문제 풀이
   - 단답형 문제만 제공
   - 분야별 필터: 웹 보안, 시스템 보안, 네트워크 보안, 암호, 애플리케이션 보안, 관리 보안
   - 난이도 표시: 기초, 중급, 고급
   - 문제별 해설 제공

2. 즉시 자동 채점
   - 답안 제출 즉시 정답/오답 표시
   - 정답 후보와 별칭을 허용
   - 빈 답안은 오답으로 처리하고 입력 안내 표시

3. 대소문자 기준 명확화
   - 문항별 정답 키에 `caseSensitive` 값을 명시
   - `caseSensitive: false`인 답은 대소문자 무시
   - `caseSensitive: true`인 답은 정확한 대소문자만 정답
   - 대소문자만 틀린 경우 별도 피드백 제공

4. 학습 기록
   - 기기 로컬에 풀이 기록 저장
   - 전체 풀이 수, 정답률, 분야별 진행률 표시
   - 오답노트 제공
   - 북마크 제공

5. 콘텐츠 정책
   - v1은 기출 경향 기반 재구성 단답형 문제만 출시 앱에 포함
   - 기출 원문 또는 원문 해설은 권리 확보 전까지 제외
   - 문항마다 출처 상태를 데이터로 관리

## MVP 제외 사항
- 서술형 문제
- rubric 기반 서술형 채점
- OpenAI API 기반 AI 채점/첨삭
- 로그인
- 클라우드 동기화
- 서버 API
- 기출 원문과 원문 해설의 앱 내 수록
- 결제, 구독, 광고
- 관리자 페이지 또는 원격 문제 업데이트

## 출시 전략
- v1은 무료 베타로 출시한다.
- iOS와 Android 동시 출시 가능한 Expo 구조를 사용한다.
- 실제 스토어 제출 전 TestFlight와 Google Play 내부 테스트로 검증한다.
- 개인정보 수집을 최소화하고, v1에서는 로컬 저장만 사용한다.
- v1 성공 기준은 “단답형 반복 학습 앱으로 충분히 빠르고 명확하게 쓸 수 있는가”이다.

## v2 후보
- 서술형 문제와 rubric 기반 채점
- 백엔드를 통한 OpenAI API 서술형 첨삭
- 로그인과 클라우드 동기화
- 문제 콘텐츠 원격 업데이트
- 권리 확보된 기출 원문 콘텐츠 팩
- 유료 프리미엄 기능 또는 구독
